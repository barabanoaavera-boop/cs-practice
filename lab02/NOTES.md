Рабочая папка — где я редактирую файлы. Индекс — куда добавляю перед сохранением. Коммит — сохранение изменений с сообщением.
Git — это программа на компьютере, которая следит за изменениями.
GitHub — это сайт в интернете, где хранятся репозитории.
Использованные команды: git status — показывает состояние файлов. git diff — показывает изменения до добавления в индекс. git diff --staged — показывает изменения после добавления в индекс.
Ветки: ветка — это отдельная линия разработки. При новом коммите ветка сдвигается вперёд. Слияние (merge) переносит изменения из одной ветки в другую.
git diff — показывает разницу между рабочей папкой и индексом (или между коммитами, если указать их).
git show — показывает полную информацию о конкретном коммите: автора, дату, сообщение и его diff.
git log — показывает историю коммитов. С флагом --oneline — кратко, с -S"..." — ищет коммиты, где появлялось/удалялось указанное слово.
git blame — показывает, кто и в каком коммите добавил каждую строку файла.
