lab04 — Воркшоп по рефакторингу

Что делает:
Читает журнал метеостанции (город;температура;дата) со стандартного ввода.
Печатает три строки:
1. Сколько записей успешно разобрано.
2. Сколько строк пропущено из-за ошибок.
3. Средняя температура самого тёплого города с одним знаком после точки.

Модули:
- stats.py — чистая логика: разбор строки, отбор корректных записей, средние, самый тёплый город.
- main.py — точка входа: читает ввод, вызывает функции из stats.py, печатает отчёт.
